House Price Prediction System

An intelligent Machine Learning application that estimates residential property prices based on house characteristics.

Project Overview

The House Price Prediction System is a Machine Learning web application built using the Ames Housing Dataset. Users can estimate the selling price of a house by entering property details through an interactive web form or by uploading a CSV file for batch prediction.

Features

Single House Prediction

Predict the estimated selling price of an individual property using its features.

Batch Prediction

Upload a CSV file to generate predictions for multiple houses simultaneously.

Machine Learning Powered

Predictions are generated using a trained Support Vector Regression (SVR) model.

Responsive Interface

Optimized for desktop, tablet, and mobile devices.
